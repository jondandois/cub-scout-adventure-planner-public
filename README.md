# Cub Scout Adventure Planner

**Find Adventures that fit what your Pack is doing.**

The Cub Scout Adventure Planner is a small, independent planning tool for Cub Scout Packs and committees. It helps you search across the Cub Scout Adventures for all six ranks and quickly see which Adventures may connect to an activity, theme, or Pack event.

The idea is simple:

> **We're doing X as a Pack. What Adventures could our different dens work on while we're there?**

## What it does

Search for a word or phrase such as:

- hike
- nature
- camping
- cooking
- art
- maps
- service

Then filter the results by rank:

- 🦁 Lion
- 🐯 Tiger
- 🐺 Wolf
- 🐻 Bear
- ⚜️ Webelos
- 🏹 Arrow of Light

Results are organized by **Adventure**, rather than by individual requirements or activities. When useful, the planner shows the requirement or activity that caused the match, so you can see why an Adventure appeared in the results.

Every Adventure links back to its corresponding page on Scouting America.

## Why it exists

Cub Scout Adventures contain a lot of useful material, but finding connections between an activity and Adventures across multiple ranks can take some digging.

This project is intended to make that discovery easier for Pack leaders and committees.

For example, if a Pack is planning a nature hike, the planner can help reveal opportunities across several ranks that might otherwise be easy to miss.

It is a **planning and discovery tool**, not an advancement-recording system.

## Source and independence

This is an **independent, community-created project** and is **not affiliated with, sponsored by, endorsed by, or administered by Scouting America**.

The planner organizes information published on the Scouting America website for easier cross-rank discovery. Scouting America remains the authoritative source for Cub Scout program requirements, Adventure information, and advancement guidance.

Requirements and program materials can change. Always refer to the official Scouting America Adventure page when planning or completing an Adventure.

## How it works

The project maintains a local copy of the Adventure content needed for search:

**Rank → Adventure → Requirement → Activity**

The local data is refreshed from the public Scouting America Adventure pages rather than performing a live search of the Scouting America website every time someone uses the planner.

The planner intentionally keeps the final experience simple: **search deeply, return useful Adventure-level results, and point you back to the official source.**

## Pack planning

The current version focuses on search and discovery.

A natural future direction is a Pack Event Planning mode where a committee could describe an event and see potential Adventure opportunities across participating ranks.

For example:

> **hike**  
> Lion · Tiger · Wolf · Bear · Webelos · Arrow of Light

The same underlying Adventure data can support that kind of planning without replacing the official Scouting America program.

## Project goals

- Make cross-rank Adventure discovery easier.
- Help Pack committees get more advancement value from shared activities.
- Keep results focused on Adventures rather than overwhelming users with individual activity pages.
- Link users back to the authoritative source.
- Keep the project small, understandable, and maintainable.
- Avoid trying to recreate or replace the official Scouting America program.
